## 一、分组原则

按「核心机制」分组，不按题材。分组服务于两个目的：
1. 同组玩法可复用同一套 UI/逻辑模板（如卡牌组的发牌/出牌/计分骨架）；
2. 新增玩法时按组规划，先补全高优先级组，避免东做一个西做一个。

4. 版图棋类组：**卡卡颂**（验证坐标/拖拽类）
5. 竞速赌运组：**德国心脏病（抢答）**（验证实时仲裁）

技术要点（踩坑备忘）：
- 新增 `js/games/xxx.js` 后在 `index.html` 底部 script 列表追加，**必须在 main.js 之前**，否则 GAME_REGISTRY 引用未定义模块会崩溃；
- 同步在 `js/main.js` GAME_REGISTRY 追加条目并 `available:true`，`js/bot.js` GAME_BRAINS 注册 bot；
- 每个新玩法完成后必须实际验证落盘（Test-Path / 页面加载），不能只看子 Agent 返回文本。
