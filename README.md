# WiFi 卡牌联机

一个纯前端（HTML + CSS + JS）的局域网卡牌游戏大厅。玩家连入同一个 WiFi 后，打开同一个网页即可建房/加入，一起玩多种卡牌游戏；在大厅里也能直接聊天约局，不用加入房间。

## 技术特点

- **纯静态页面**：直接部署到 GitHub Pages，无需服务器。
- **局域网 P2P**：游戏数据走 WebRTC DataChannel，同一 WiFi 下直接点对点通信，延迟极低。
- **PeerJS 信令**：仅用于「找房间」配对；配对成功后不再依赖服务器。
- **自包含依赖**：PeerJS 与 MQTT 客户端库均已本地化到 `js/vendor/`，不依赖外部 CDN。
- **移动端优先**：响应式布局，卡牌用纯 CSS/SVG 绘制。
- **支持人机**：每个玩法都有人机 AI，没有其他玩家也能自己玩。

## 玩法

### 抽鬼牌（2–6 人）

去掉黑桃 Q，51 张牌发完，各人先出掉手里的对子。然后轮流从下家抽牌：

1. **整理阶段**：被抽牌的人先调整手牌顺序（点两张牌交换位置），然后点「亮牌」。
2. **抽牌阶段**：抽牌的人点击对方一张背面牌，抽走该位置。
3. 抽到能凑对的牌就打出；最后手里剩下鬼牌的人输。

### 21 点（2–8 人）

与庄家比点数，越接近 21 且不爆为胜；A 可作 1 或 11。

### UNO（2–6 人）

打出与上一张颜色或数字相同的牌；功能牌（跳过、反转、+2、万能、+4）可以干扰对手节奏，先出完手牌者获胜。

### 女巫的毒药（3–6 人）

往 3 口锅里放药水牌，锅值超过 13 就得收锅。每局结算罚分：收集某色药水最多者该色免罚，其余玩家按该色点数计罚；毒药牌每张 2 罚分。多局累积，罚分最少者胜。

### 狼人杀（6–8 人）

经典四身份（狼人 / 预言家 / 女巫 / 平民）。夜晚狼人袭击、预言家查验、女巫救/毒，白天公布死亡并投票放逐。狼人全灭则好人胜；存活狼人数不少于存活好人数则狼人胜。

### 卡波（2–4 人）

记牌换牌的记忆推理游戏。52 张牌（0×2、13×2、1–12 各 4），每人 4 张暗牌、开局偷看其中 2 张。回合抽牌堆 / 拿弃牌堆 / 喊「卡波」三选一；7/8 偷看自己、9/10 偷看别人、11/12 与别人换牌（特殊牌只能从牌堆抽出并弃掉时发动）。喊「卡波」触发终局，点数最低者记 0 分；凑齐 12、12、13、13 触发「神风」直接 0 分、其余人 +50。累计分数超过 100 分时总分最低者获胜。

### 赛马（2–8 人）

四花色（♠♥♦♣）马沿 A~K 共 13 格赛道竞速的纯运气玩法。开局每人认领一匹看好的马（可重复认领）；房主洗牌后自动逐张翻牌，翻到哪个花色那匹马就前进一步。最先翻完自己 13 张（跑到终点）的花色夺冠，认领它的玩家获胜。比赛过程中房主可「加速」或「直接揭晓」。

### 飞行棋（2–4 人）

经典骰子地图竞速（v2 重做）：开局由房主选择地图，每张地图含不同特殊格——⚡加速格（下次移动步数加成）、🚀跳跃台（落格立即额外前进）、⚠️陷阱格（落格立即倒退）、🌀传送门（落格立即传送至指定格），并配有起飞/踩踏/到家/胜利全套特效与骰子旋转动画。每人 4 架飞机停在停机坪，掷到 6 才能起飞（每次只起飞指定一架）并**再掷一次**。飞机沿外圈 52 格轨道顺时针行进（每色 13 格，起点为安全格），进入同色终点跑道后恰好掷到终点数值才可进港；踩中敌方单机将其送回停机坪（安全格与敌方叠机不可踩），己方多架同格可叠机同行。率先让全部 4 架飞机进港的玩家获胜。

### 泡泡龙·对抗（2 人）

双人各自一块蜂窝六边形场地（12 行 × 10 列）轮流发射：从底部发射器选角度发射泡泡，撞顶或粘附后按六向相连消除 3 个及以上同色泡泡，悬空泡泡随之掉落。每次消除会向对手注入**灰色垃圾泡泡**（数量 = 消除数 − 2，下限 1；掉落泡泡按一半数量折算），对手场地底部整体上移。谁先堆满顶到顶线、或轮到自己时供弹耗尽，谁输；双方都爆则后爆者胜。

### 泡泡龙·合作（2 人）

两人共用一个场地轮流发射，无垃圾泡泡机制。目标是合力清空全场初始泡泡：任何一发的消除/掉落都可推进进度条（显示剩余泡泡数与双方累计消除数）。场地堆满到顶线、或供弹耗尽但场上仍有泡泡，则共同失败；全场清空即全队胜利。

### 情书 Love Letter（2–6 人）

16 张角色牌的推理淘汰聚会游戏：守卫×5、牧师×2、男爵×2、侍女×2、王子×2、国王×1、伯爵夫人×1、公主×1。每轮暗置移除 1 张后每人发 1 张手牌，轮流抽 1 张、打出 1 张并发动角色效果淘汰对手——守卫猜对手手牌点数、男爵比点数、王子强制换牌、国王交换手牌，打出或弃掉公主则立即出局。牌堆耗尽或仅剩 1 人存活时，存活者比手牌点数决定本轮胜者。先达到目标分（2 人 5 分 / 3–4 人 4 分 / 5–6 人 3 分）者赢得整局。

### 谁是牛头王 Take 6（2–10 人）

经典数字出牌博弈：104 张数字牌，尾数 5 的牌 2 个牛头、尾数 0 的 3 个、双数（11/22…99）5 个、55 号 7 个、其余 1 个。每人 10 张手牌、桌面 4 行，每回合所有人同时暗出一张，按数字升序放入差值最小的行尾；放入后满 6 张必须吃走前 5 张计分，牌比所有行尾都大时也须选一行整行吃掉。10 回合后牛头总数最少者获胜。

### 炸弹猫 Exploding Kittens（2–5 人）

俄罗斯轮盘式淘汰游戏：牌堆中混有若干张「爆炸猫」，轮流摸一张牌，摸到爆炸猫且没有「拆弹」牌立即出局；摸到其他牌加入手牌，可在抽牌前打出效果牌——拆弹（保命并放回一张爆炸猫入堆）、跳过（免抽一次）、攻击（让下家连续抽两次）、透视（偷看牌堆顶 3 张）、洗牌（随机重排牌堆，可用「暂停」打断）。坚持到最后未被炸的玩家获胜。

### 海盐与纸 Sea Salt & Paper（2–4 人）

海洋主题收集卡牌：海洋 / 渔夫 / 海盗 / 美人鱼 / 海马 / 船长 / 海鸥 / 鲸鱼 / 海豚等类别，每种卡牌 4 张。回合二选一：从牌堆抽 1 张加入手牌并继续，或直接「收分」结算本局分数。同点数三张 10 分、两张 3 分；同色系三张以上 3 分起、两张 2 分，特殊类有专属计分。分数满足 10/15/20 档可多次「翻面加注」——把本局已收分数翻倍压上，赌下一局能收回更高分，一旦中途收不回来就输掉压注。先达到目标分（2 人 35 / 3 人 30 / 4 人 25）者获胜。

### 翻牌7 Flip 7（2–8 人）

数字推运气的停手博弈：牌堆为 1–7 各多张的数字牌。回合从当前玩家开始连续翻牌，把翻出的数字累加到本回合总和，总和超过 21 或翻到数字 7 即「爆炸」、本回合收益清零；可以随时「停止」，把当前总和留下的数字牌收入面前，凑成一对（同数字两张）可额外加分。所有人都爆炸或放弃后，累计分最高者获胜。

### 深海小队 The Crew（2–5 人）

合作吃墩玩法：40 张海豚牌（5 色 × 数字 1–9）。每局发牌后生成一张**任务目标卡**——指定某位玩家必须吃到某色某数字的牌。所有人共同按吃墩规则出牌（首牌定色、有同色必须跟同色、同色数字最大者吃墩）：

1. 全队目标是把本局任务牌**送到指定玩家手里**：任务牌被目标玩家吃到则本局成功，被其他玩家吃到则本局失败需重试。
2. 共 9 局，逐局发放新任务；9 局任务全部完成即全队胜利。
3. 支持「通讯」简化省略：不开启额外通信指令，全队凭公开牌面与墩面信息默契配合。

### 花火 Hanabi（2–5 人）

合作烟花玩法：25 张牌（5 色 × 数字 1–5）。每位玩家**看不到自己的手牌**，只能看到其他玩家的手牌与牌堆/弃牌信息。每回合三选一：

1. **打出**：把手里某张牌打到对应颜色的烟花堆上，必须严格按 1→5 顺序；打对则烟花推进，打错扣 1 个失误 token（初始 3 个，扣完失败）。
2. **弃牌**：弃掉手里某张牌进弃牌堆，恢复 1 个提示 token（上限 8 个）。
3. **提示**：选择一名其他玩家，公开告知其手牌中所有**某种颜色**或**某个数字**的牌（消耗 1 个提示 token）。

通过提示标记推理自己的手牌，五色烟花全部完成（25 张）即全队胜利；牌堆耗尽则按已完成烟花数计分。

### 阿瓦隆 The Resistance: Avalon（5–10 人）

身份隐藏的组队投票博弈，好人（梅林/珀西瓦尔/亚瑟/忠诚骑士）与坏人（莫德雷德/莫甘娜/奥伯伦/刺客）互不知晓，共 5 局任务、先赢 3 局者胜：

1. **角色分配**：按人数随机发放隐藏角色。梅林开局能看到所有坏人（除莫德雷德）；珀西瓦尔能看到梅林与莫甘娜二选一；坏人彼此相识（奥伯伦除外）。
2. **组队**：队长按本局人数提名队伍（2–4 人），全员对队伍投票——过半赞成则成队，否则换下一任队长重新提名（连拒计数，连拒 5 次任务直接失败）。
3. **任务**：成队后队伍成员秘密投「成功/失败」票，坏人可投失败票破坏任务（第 4 局任务需 2 张失败票才失败）。任务成功/失败后按局推进，先赢 3 局者胜。
4. **刺杀翻盘**：若好人先赢 3 局，坏人阵营的刺客立即指认一名玩家是梅林——指认正确则坏人翻盘获胜。

### 秘密希特勒 Secret Hitler（5–10 人）

法西斯 vs 自由的阵营博弈：法西斯阵营含 1 名「希特勒」，自由阵营 3 张自由政策即胜；法西斯 6 张法西斯政策或成功暗杀希特勒即胜：

1. **角色分配**：随机总统链顺时针轮流执政；法西斯成员彼此知晓、自由阵营互不知晓（希特勒对法西斯可见但开局不知谁希特勒）。
2. **选举**：总统提名一名首相，全体玩家投票（过半赞成通过，否则连续选举失败累计，5 次失败后自动翻开牌堆顶政策并重置计数）。
3. **立法**：通过后总统抽 3 张政策牌弃 1、首相从剩余 2 张选 1 执行；政策为自由或法西斯，执行后推进对应轨道。
4. **法西斯特权**：法西斯政策到达 3/4/5 张时，总统依次触发「调查一名玩家阵营 / 指定下任总统 / 暗杀一名玩家」；暗杀到希特勒则法西斯立即获胜。

### 矮人矿坑 Saboteur（3–10 人）

好矮人挖金 vs 坏矮人破坏的卡牌博弈，共 3 局、按金块计分：

1. **角色分配**：按人数分配好/坏矮人（仅自己可见）；目标是从起点铺路到 3 个金矿之一。
2. **铺设**：每人手牌含路径牌（直/弯/十字/死路）与行动牌（破坏、修理、地图、落石、宝藏）。轮到自己时打 1 张路径牌连到已有路网上（可旋转），或打行动牌干扰他人，或弃牌。
3. **胜负**：路径连到金矿即好矮人胜利并翻开金矿（3 个矿只有 1 个是真金矿）；牌堆耗尽时坏矮人胜利。局末按结果给好/坏矮人发金块，3 局后金块最多者获胜（单人最高者胜，平局共享）。

### 染·钟楼谜团 Blood on the Clocktower（5–12 人）

说书人（主机程序）自动调度的社交身份推理游戏，采用 Trouble Brewing 精简角色池：镇民 13 选（洗牌人/图书馆员/调查员/厨子/共情者/占卜师/酒鬼/圣徒/士兵/守夜人/处女/猎人/市长）、爪牙（下毒者/男爵/间谍）、恶魔（小恶魔）。

1. **身份分配**：按人数配比 恶魔 1 + 爪牙（5-6 人 1 名、7-8 人 2 名、9-12 人 3 名）+ 镇民，主机随机发身份并私发首夜信息（洗牌人/图书馆员/调查员/厨子/间谍等）。
2. **夜晚**：主机按角色顺序私下调度行动——下毒者下毒（被毒者当晚信息失效）→ 小恶魔杀人（士兵免疫）→ 占卜师占卜；共情者每夜被动查看左右邻居邪恶数量。行动结果只私发本人。
3. **白天**：全员公开聊天讨论；存活玩家可提名一名玩家并发起全体投票，赞成票过半即处决。
4. **死亡不退出**：被处决或夜间被杀后仍可发言，但失去提名与投票权。
5. **胜负**：恶魔死亡 → 善良方胜利；存活仅剩 2 人且恶魔仍在 → 邪恶方胜利；圣徒被处决 → 邪恶方立即胜利。

## 聊天

- **大厅聊天（无需加入房间）**：打开网页即可和所有在线玩家聊天。
  - 因为纯静态无后端、浏览器无法在局域网内「广播」发现陌生人，大厅聊天借助免费公共 MQTT broker（`broker.emqx.io`）中转，零注册。
  - ⚠️ 大厅聊天需要**外网**（能连上公共 broker），且是**全局公共频道**，请勿发送手机号、密码等敏感信息。
- **房间内聊天**：加入房间后自动切换为 WebRTC 局域网直连，不经公共服务器，更私密。
- 顶部栏 💬 按钮打开聊天弹窗，未读消息有红点提示。

```bash
cd wifi-card-games

```

然后打开 http://127.0.0.1:8000。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个空仓库（例如 `wifi-card-games`）。
2. 把本项目推送到仓库：
   ```bash
   git remote add origin https://github.com/my-username/wifi-card-games.git
   git push -u origin main
   ```
3. 进入仓库 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**，Branch 选 `main` / `(root)`，保存。
5. 等待几分钟，访问 `https://my-username.github.io/wifi-card-games`。

> 建议把仓库名改成 `my-username.github.io`，这样可以直接用 `https://my-username.github.io/` 访问，地址更短。

## 现实中一起玩

1. 所有人连接**同一个 WiFi**（手机开热点也可以）。
2. 房主打开网页，点击「创建房间」并选择玩法。
3. 把 4 位房间码告诉其他人。
4. 其他人输入房间码加入，房主点击「开始游戏」。

### 手机热点注意事项

- **开热点的手机必须有移动数据（外网）**，因为配对阶段需要访问 PeerJS 云端信令。
- 配对成功后，出牌/发牌数据走热点局域网直连，几乎不耗流量。
- 部分安卓热点有「AP 隔离 / 客户端隔离」开关，打开后设备间不能互访，**必须关闭**。
- 必须 HTTPS：GitHub Pages 天然满足；本地用 `http://192.168.x.x` 测试会被浏览器拒绝。

## 自定义与扩展

- **新增玩法**：在 `js/games/` 实现 `init(ctx)` 和 `handleMessage(from, data)` 接口，然后在 `js/main.js` 的 `GAME_REGISTRY` 注册。
- **切换信令服务器**：修改 `js/net.js` 中 `new Peer(...)` 的 `host`/`port`/`path`/`secure` 参数即可。
- **切换大厅聊天 broker**：修改 `js/lobby.js` 顶部的 `BROKERS` 数组。
- **离线手动配对**：若希望热点无外网也能玩，需要实现 SDP 二维码/口令交换（绕过信令服务器）。

## 浏览器支持

需要支持 WebRTC 的现代浏览器：Chrome / Edge / Safari / Firefox。iOS Safari 可用，但建议保持前台。
